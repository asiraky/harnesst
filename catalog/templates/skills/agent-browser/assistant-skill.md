# Agent Browser (installed skill)

Gives the agent the `agent-browser` CLI in its sandbox plus a skill covering navigation,
accessibility snapshots, clicking/filling by refs, and screenshots. Design browsing work as
sandbox-shell steps in the agent's instructions; no extra tools or channels are involved.
