# Building Cloudflare apps (installed skill)

Teaches the agent to build a React + Vite SPA with a Worker API backend: scaffold choice,
layout, wrangler.jsonc semantics, SPA-vs-Worker routing, verify workflow, bindings. Building
only — deploying is the separate `deploying-cloudflare-apps` skill; pair them for ship-to-prod
requests.
