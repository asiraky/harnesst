# Clarifying A Request

Find the facts yourself before asking about preferences. Establish the project through ledger-list-projects and read its docs. State unavailable facts as open questions.

Ask one question per turn: the unresolved decision with the largest scope impact whose prerequisites are settled. Recommend an answer with a brief reason. Probe vague answers with a concrete example; dependent questions wait.

Scale to the work. Finish when material choices are answered or explicitly delegated. Write the problem, testable acceptance criteria, exclusions and decisions with reasons for someone outside the conversation. Save unfinished requests with visible open_questions; say they are not ready to build.

Use the ledger skill for recording the spec and durable human questions.
