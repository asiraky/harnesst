# Deploying Cloudflare apps (installed skill)

Teaches the agent wrangler config and deploys, resource provisioning (KV/D1/R2/Queues/Pages),
dry-runs, and getting deploy credentials into CI. Cloudflare only — building the app is the
separate `building-cloudflare-apps` skill. Deploy credentials are agent secrets the human
supplies.
