# Google Sheets usage (installed skill)

Teaches the agent A1 notation, read-before-write discipline, RAW vs USER_ENTERED, append vs
update, and batchUpdate request shapes. Guidance only — the tools themselves come from the
Google Sheets **connection**, which must also be installed and connected.
