# harnesst MCP authoring (installed skill)

Teaches an agent to author eve agents through harnesst's MCP server: save complete files, review
every pending change, publish once, and poll deployments until live. This is for agents that
BUILD other agents via MCP — it does not change how the agent itself is configured.
