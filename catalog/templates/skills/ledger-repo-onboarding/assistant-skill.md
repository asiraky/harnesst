# Ledger repository onboarding (installed skill)

Teaches the team's infra agent to create organization repositories with `gh` and connect any
repository to the team ledger: Actions secrets, the ledger workflow and helper, and the optional
Cloudflare deploy workflow. It needs the infra GitHub App (Administration, Workflows, Secrets and
Variables write) and the provisioned `LEDGER_GITHUB_ACTOR_KEY`; the setup wizard grants both.
