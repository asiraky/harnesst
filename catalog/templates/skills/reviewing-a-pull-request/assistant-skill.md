# Reviewing a pull request (installed skill)

Teaches the agent a two-axis review from a local checkout — standards (repo conventions plus a
code-smell baseline) and spec (does it do what the issue asked) — delivered as one ranked
review. Pair it with the GitHub channel/bundle so review requests arrive as PR events and the
agent can post as the App.
