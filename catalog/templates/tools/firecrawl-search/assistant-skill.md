# Web Search (installed tool)

Searches the live web and optionally returns page content, routed through a service that
bypasses the bot protection blocking plain fetches. When designing research flows, reach for
this tool rather than raw fetches from the sandbox. One-way lookup only — no wakes, no
human contact.
